# Ubatuba 2026

Site da viagem do grupo de 18 a 20 de dezembro de 2026, com roteiro, hospedagem, divisão de gastos e checklist.

## Publicar no GitHub Pages

1. Acesse **Settings → Pages** neste repositório.
2. Escolha **Deploy from a branch**.
3. Selecione **main** e **/(root)**, depois **Save**.

Endereço esperado: https://maribarbalho.github.io/ubatuba-2026/

## Fotos reais da hospedagem

O site já está configurado para carregar as **nove fotos** quando os arquivos estiverem disponíveis em:

- `assets/casa-01.jpg` até `assets/casa-09.jpg`

Essas imagens estão no ZIP enviado no ChatGPT. **Ao atualizar o GitHub, envie somente a pasta `assets`, com as fotos. Não substitua o `index.html` pelo do ZIP antigo**, porque o design editorial mais recente já está publicado neste repositório.

A galeria mostrará espaços reservados enquanto as imagens ainda não estiverem no GitHub. Depois que forem enviadas, basta recarregar a página.

## Informações da viagem

- O aluguel de R$ 1.300 é dividido entre sete pessoas.
- Gasolina estimada em R$ 300 e pedágios estimados em R$ 100, divididos somente entre os cinco passageiros do **Carro 1**.
- A trilha de sábado é opcional, com transporte de barco a consultar previamente.
- A programação e os valores podem mudar; horários de check-in/check-out devem ser confirmados com a anfitriã.

**Observação:** os itens do checklist são salvos localmente no navegador, não sincronizados entre os participantes.
